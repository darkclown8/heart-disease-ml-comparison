# Heart disease prediction: comparison of six ML models (Cleveland dataset)

Code for the paper "Machine Learning for Detecting Heart Disease: Comparing Six Models on the Cleveland Dataset".

- Data: UCI Heart Disease (Cleveland), downloaded automatically with `ucimlrepo` (id=45)
- Models: logistic regression, SVM, random forest, XGBoost, MLP, kNN
- Run: open `cleveland.ipynb` and use Kernel > Restart & Run All
- Python 3.13.14, scikit-learn 1.9.1, XGBoost 3.4.1, SHAP 0.54.1
- Files: results.csv, efficiency.csv, tests.csv, fold_scores.csv, best_params.csv, table1.csv, and figures (eda.png, figures.png, shap.png)
